# Contribuindo

## Branches e commits

- Crie branches a partir de `main` com o padrão `tipo/resumo-curto`, por exemplo `feat/login` ou `fix/sincronizacao-offline`.
- Use Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:` e `ci:`.
- Mantenha cada pull request focado, com testes e atualização de documentação quando aplicável.

## Revisão

Toda alteração em `main` requer pull request, uma aprovação e CI verde. Alterações que tratem dados de saúde, localização, consentimento ou autenticação precisam de revisão de segurança/privacidade antes do merge.
